# 범용 프로젝트 구조

```text
사업계획서_프로젝트/
├─ 00. 시작하기/
├─ 01. 사업정보/
│  └─ 공유가능 원본/
├─ 02. 목적 및 요구사항/
│  └─ 원본/
├─ 03. 사업계획서양식/
│  ├─ 원본/
│  └─ 작업용 HWPX/
├─ 04. 조사자료/
│  └─ 출처원문/
├─ 05. 작성초안/
├─ 06. 검토결과/
├─ 07. 최종본/
└─ 99. 원본백업/
```

## 운영 규칙

- 지원사업 공고가 없으면 `02. 목적 및 요구사항`에 독자, 의사결정, 필수 장·절을 기록한다.
- 양식이 없으면 `03. 사업계획서양식`을 비워 두고 Markdown 초안부터 작성한다.
- 내가 알고 있는 정보, 외부 확인이 필요한 내용, 앞으로 할 계획을 구분한다.
- 원본은 원본 폴더와 백업에 보관하고 직접 수정하지 않는다.
- AI가 만든 문안은 `05. 작성초안`, 검토 결과는 `06. 검토결과`, 승인된 결과만 `07. 최종본`에 둔다.
- 파일명은 `YYYYMMDD_문서명_v01` 형식을 권장한다.
