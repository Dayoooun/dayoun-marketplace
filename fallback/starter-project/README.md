# 범용 사업계획서 스타터 프로젝트

설치나 개인자료 준비가 늦어도 바로 시작할 수 있도록 폴더와 빈 작업표, 여섯 개 스킬을 함께 넣었습니다.

- 먼저 “누가, 어떤 상황에서, 어떤 문제를 해결하기 위해 이 사업을 이용하는가?”에 답합니다.
- `00. 시작하기/계획프로필.json`에서 문서 목적, 독자, 마감, 공식 요구사항 유무를 정리합니다.
- `00. 시작하기/작업범위.md`에서 QUICK / SECTION / FULL 중 이번 작업 범위를 고릅니다.
- Codex와 Antigravity는 `.agents/skills`, Claude Code는 `.claude/skills`의 같은 스킬을 읽습니다.
- `complete-business-plan` 스킬을 사용해 DEMO 또는 PARTIAL 모드로 시작해 달라고 요청합니다.
- 원본은 `99. 원본백업`과 각 원본 폴더에 보관하고 직접 수정하지 않습니다.
- 내가 알고 있는 정보, 외부 확인이 필요한 내용, 앞으로 할 계획을 구분합니다.
- 지원사업 공고가 있으면 공식 원문을 우선하고, 없으면 독자와 의사결정 목적에 필요한 장·절을 정합니다.
- HWPX는 원본 보존, 사용자 승인, 양식 검증이 확인된 경우에만 선택적으로 사용합니다.
