# 스타터 프로젝트

설치·Python·개인자료 준비가 늦어진 참가자가 바로 수업에 합류하도록 폴더와 빈 작업표를 미리 만든 프로젝트입니다.

- 아이디어 한 문장만 있다면 파일을 채우기 전에 “누가, 어떤 상황에서, 어떤 문제를 겪는가”라는 질문 하나부터 답합니다.
- `00. 시작하기/사전점검.md`에서 Green / Yellow / Red와 DEMO / PARTIAL / REAL을 먼저 선택합니다.
- `00. 시작하기/프로그램프로필.json`에는 현재 공식 공고에서 확인한 프로그램 정보만 기록합니다.
- 이 폴더를 Codex 또는 Antigravity에서 열면 `.agents/skills`, Claude Code에서 열면 `.claude/skills`의 같은 교육용 스킬 6개를 별도 설치 없이 사용할 수 있습니다.
- 개인자료가 없거나 공개하기 어렵다면 옆 폴더의 `offline-evidence-pack`과 함께 DEMO로 진행합니다.
- 제출본 원본은 복사하지 말고 `99. 원본백업`에 별도로 보관합니다.
- 먼저 공백진단표, 검증·활동 기록, 멘토링 변화기록, 다음 공식 마감 실행카드를 완성합니다.
- 회사 내부 입력은 F001 계열, 네 결과물에서 검증할 핵심 주장은 C001로 분리합니다.
- HWPX 자동치환은 수정 허용과 양식 사전 검증이 확인된 선택 트랙에서만 진행합니다.
