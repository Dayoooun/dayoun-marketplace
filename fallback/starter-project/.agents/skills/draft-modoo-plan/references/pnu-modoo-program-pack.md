# 부산대학교 모두의 창업 프로그램 기준팩

이 파일은 프로그램프로필의 `program_pack`이 `pnu-modoo`이고 사용자가 현재 공식 공고·평가표를 제공한 경우에만 읽는다. 대화에 등장한 날짜나 과거 일정은 기본값으로 사용하지 않는다.

## 공개 평가영역 예시

| 영역 | 확인 질문 | 권장 산출물 |
|---|---|---|
| 도전의 진정성 | 왜 이 문제를 발견했고 왜 본인이 해결하려는가 | 문제 발견 경험, 고객 사례, 개발 배경 |
| 사회적 가치 | 기존 대안과 무엇이 다르고 누구에게 어떤 변화가 생기는가 | 경쟁대안표, 기대효과 |
| 아이디어 구체성 | 누가 쓰고 어떻게 구현·검증·사업화할 것인가 | 목표고객, BM, MVP, 실행계획 |

## 사용 규칙

- 현재 공식 공고 원문이 이 파일보다 우선한다.
- 공식 가중치가 공개되지 않았으면 자가진단 점수를 공식 점수로 표시하지 않는다.
- 제출 후 수정 가능 여부와 현재 단계는 운영기관에 확인하고 프로그램프로필에 기록한다.
- 특정 강의일·마감일을 스킬 기본값으로 저장하지 않는다.
