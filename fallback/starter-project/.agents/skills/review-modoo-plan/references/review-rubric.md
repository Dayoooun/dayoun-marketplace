| 영역 | 질문 | 상태 |
|---|---|---|
| 진정성 | 대표자의 실제 경험과 문제의식이 구체적인가 | PASS/WARN/BLOCK |
| 차별성 | 비교 대상과 근거가 있는가 | PASS/WARN/BLOCK |
| 기대효과 | 수혜자와 변화가 연결되는가 | PASS/WARN/BLOCK |
| 시장성 | 고객·시장·경쟁 근거에 출처가 있는가 | PASS/WARN/BLOCK |
| 실현 가능성 | MVP, 자원, 일정, 검증지표가 있는가 | PASS/WARN/BLOCK |
| 사실성 | 현재·가정·계획을 구분했는가 | PASS/WARN/BLOCK |
| 일관성 | 같은 수치·고유명사·기간이 문서 전체에서 같은가 | PASS/WARN/BLOCK |
| 보안 | 개인정보와 비공개정보가 제거되었는가 | PASS/WARN/BLOCK |
| 독창성 | 장문 복사와 아이디어 도용 위험이 없는가 | PASS/WARN/BLOCK |

|---|---|---|

| 치환 | template-field-map과 실제 치환 대상·횟수가 같은가 | PASS/WARN/BLOCK |
| 누락 | NOT_FOUND, SKIPPED_EMPTY, 미치환 중괄호가 0건인가 | PASS/WARN/BLOCK |
| 구조 | HWPX ZIP·XML 구조검증을 통과했는가 | PASS/WARN/BLOCK |
| 육안 | 한글에서 표·줄바꿈·글자 겹침·페이지 넘김을 확인했는가 | PASS/WARN/BLOCK |
