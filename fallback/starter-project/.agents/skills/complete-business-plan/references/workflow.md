# 범용 사업계획서 작업 흐름

| 단계 | 확인할 것 | 기본 결과물 | 통과 기준 |
|---|---|---|---|
| 1. 목적 | 독자, 결정, 제출·사용 시점 | 목적·요구사항표 | 목적과 범위가 한 문장으로 명확함 |
| 2. 자료 | 원본, 회사 정보, 양식, 참고자료 | 입력자료목록 | 원본과 작업 사본을 구분함 |
| 3. 진단 | 필수 항목과 현재 내용 | 보완점 진단표 | 우선순위와 이유가 있음 |
| 4. 조사 | 시장·고객·경쟁·수치 주장 | 조사기록, 출처목록 | 출처·날짜·단위·한계를 기록함 |
| 5. 구성 | 문제부터 실행계획까지의 연결 | 이야기 구조표 | 앞뒤 논리가 이어짐 |
| 6. 작성 | 확인된 정보, 가정, 계획 | 장·절별 초안 | 근거 없는 내용은 확인 필요로 표시함 |
| 7. 검토 | 누락, 일관성, 사실성, 표현 | 검토표, 수정본 | 범위 내 BLOCK이 없음 |
| 8. 승인 | 최종 표현과 공개 범위 | 승인기록 | 사용자가 최종 문안을 확인함 |
| 9. 출력 | Markdown, 문서, 선택 HWPX | 최종본, 변경기록 | 원본 보존과 버전 구분이 됨 |
| 10. 실행 | 다음 의사결정이나 검증 | 실행카드 | 담당·기한·완료 기준이 있음 |

## 목적별 우선 확인

| 목적 | 우선 기준 |
|---|---|
| 지원사업·공모 | 공식 공고, 평가표, 작성요령, 제출 양식 |
| 투자·IR | 성장 가능성, 시장, 팀, 실적, 자금 사용계획 |
| 사내 검토 | 전략 적합성, 자원, 일정, 손익, 위험 |
| 대출·제안 | 상환·수행 가능성, 계약 조건, 현금흐름, 증빙 |
| 자율 계획 | 독자와 의사결정 목적에 맞춘 필수 장·절 |

공식 자료가 있으면 일반 기준보다 항상 우선한다. 공식 자료가 없으면 그 사실을 밝히고 일반 기준을 질문 목록으로만 사용한다.
