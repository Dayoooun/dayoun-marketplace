# 사업계획서 프로젝트 만들기

## 절차

1. 사용자가 원하는 프로젝트 경로, 트랙, 작업 모드(DEMO / PARTIAL / REAL)를 확인한다. 트랙이 불명확하면 unknown, 작업 모드가 불명확하면 PARTIAL을 사용한다.
2. scripts/create_project.py를 실행한다.

~~~powershell
python scripts/create_project.py --path "C:\작업\모두의창업_사업계획서" --track unknown --mode PARTIAL
~~~

3. 생성 결과를 확인하고 00. 시작하기/프로젝트상태.md, 사전점검.md, 입력자료목록.csv, 실습범위카드.md를 읽는다.
4. 사용자가 제공한 파일은 원본을 보존한 복사본만 해당 폴더에 두고 입력자료목록에 공개등급·마스킹·읽기 상태를 기록한다.
   - 회사·대표·아이템 자료: 01. 회사내용/공유가능 원본
   - 공고·평가표·작성요령: 02. 공고문 및 평가지표/원본
   - 원본 HWP: 03. 사업계획서양식/원본 HWP 보관
   - 한글에서 저장한 작업용 HWPX: 03. 사업계획서양식/작업용 HWPX
5. REAL은 트랙, 목표 결과물, 수정 가능 여부, 공유 가능한 입력이 확인되지 않으면 다음 단계로 진행하지 않는다.
6. Python이나 설치가 실패하면 빈 프로젝트 생성을 반복하지 말고 제공된 스타터 프로젝트로 전환한다.
7. 99. 원본백업은 수정하지 않는다.
8. 기존 파일은 사용자가 명시적으로 요청하지 않는 한 덮어쓰지 않는다.

폴더별 역할은 references/project-layout.md를 읽는다.
