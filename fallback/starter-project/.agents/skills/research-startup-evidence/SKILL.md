# 시장조사와 증거원장

## 입력

- 00. 시작하기/입력자료목록.csv
- 00. 시작하기/실습범위카드.md
- 00. 시작하기/요구사항추적표.csv
- 01. 회사내용/회사사실표.md
- 02. 공고문 및 평가지표의 공고·평가자료
- 04. 시장조사 리서치/조사질문.md

## 조사 절차

1. 실습범위카드에서 선택한 핵심 주장 하나부터 질문으로 바꾼다.
2. Green 경로의 최신 정보는 반드시 웹에서 확인한다. Yellow·Red는 제공된 오프라인 근거팩으로 같은 기록법을 연습한다.
3. 정부·공공기관·법령·통계 원문·학술논문·기업공시 같은 1차 자료를 우선한다.
4. 검색결과 요약만 사용하지 말고 원문을 연다.
5. 정량 근거에는 출처, 발표일 또는 기준연도, 단위, 조회일을 기록한다.
6. 경쟁사·시장 전망은 사실과 분석을 구분한다.
7. 2시간 실습에서 선택한 핵심 주장 하나는 모든 결과물에서 C001로 고정한다. 추가 주장은 증거원장의 마지막 번호 다음부터 C002 형식으로 부여한다. 회사사실표의 F001 계열과 섞지 않는다.
8. 네트워크가 없으면 수치를 만들지 않는다. 오프라인 근거팩이 있으면 출처·한계 기록을 연습하고, 없으면 조사질문과 필요한 출처 목록만 작성한다.

## 결과물

- 04. 시장조사 리서치/시장조사.md
- 04. 시장조사 리서치/경쟁사비교.csv
- 04. 시장조사 리서치/검증활동기록.md
- 00. 시작하기/증거원장.csv

2시간 교육 경로에서는 C001 한 건만 선택해 검증활동기록에 출처·기준일·확인 내용·한계·다음 검증 행동을 남기면 완료한다. 공백진단표·변화기록·실행카드·1분 IR에서도 같은 C001을 사용하고 여러 주장을 한꺼번에 조사하지 않는다.

## 금지

- 출처 없는 시장규모와 성장률 생성
- 경쟁사 기능·가격을 기억만으로 단정
- 사용자의 아이디어를 공개 검색어에 그대로 노출
- 긴 원문 복사
- 확인되지 않은 자료를 확인 상태로 표시

출처 등급과 증거원장 열은 references/source-policy.md를 읽는다.
