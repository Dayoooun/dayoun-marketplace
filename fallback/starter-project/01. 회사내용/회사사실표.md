# 회사사실표

근거가 없으면 내용을 만들지 말고 {확인필요}로 남깁니다. 회사 내부 입력은 F001 형식의 fact_id를 사용하고, 외부·고객 근거로 검증할 핵심 주장은 증거원장에서 C001로 관리합니다.

| fact_id | 구분 | 내용 | 근거 파일·위치 | 상태 |
|---|---|---|---|---|
| F001 | 대표자 문제 발견 경험 |  |  | 확인필요 |
| F002 | 아이템 한 문장 |  |  | 확인필요 |
| F003 | 목표고객 |  |  | 확인필요 |
| F004 | 현재 보유 기술·자원 |  |  | 확인필요 |
| F005 | 확인된 실적 |  |  | 확인필요 |
| F006 | 향후 계획 |  |  | 계획 |
