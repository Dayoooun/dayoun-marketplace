# 핵심초안

## 문제와 고객

사업계획서를 처음 작성하는 예비창업자는 회사자료·공고문·시장근거를 여러 폴더와 채팅에서 관리하면서, 어떤 근거가 어느 문장에 연결되는지 다시 확인하는 데 어려움을 겪을 수 있습니다. [C001] 이 판단은 교육용 가상 인터뷰에 기반하므로 실제 사업에서는 고객 인터뷰로 다시 검증해야 합니다.

## 해결책과 다음 검증

모두랩은 폴더, 증거원장, 검토표와 HWPX 치환표를 하나의 작업 순서로 연결합니다. [C002] 다음 공식 마감 전 예비창업자 5명에게 사용하게 하고 작업 완료시간과 누락항목 변화를 기록합니다.
