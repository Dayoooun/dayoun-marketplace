# 수업 대체자료

개인 환경이나 자료 준비 상태에 따라 아래 세 경로 중 하나를 사용합니다.

| 경로 | 사용 조건 | 수업 목표 |
|---|---|---|
| Green | GPT·Codex·Python·웹이 정상 | 개인자료로 네 가지 필수 결과물 작성, 필요 시 파일형 확장 |
| Yellow | GPT는 가능하지만 설치·웹·개인자료 일부가 부족 | 로컬 스킬이 포함된 스타터 프로젝트와 오프라인 근거팩 사용 |
| Red | 도구 실행이나 사용량에 문제가 있음 | 완성 예시를 짝과 검토하고 인쇄·디지털 워크시트 작성 |

## 포함 자료

- `offline-evidence-pack`: 인터넷이 없어도 근거 분류와 주장 연결을 연습하는 자료
- `starter-project`: 폴더, 빈 작업표, 로컬 스킬 6개가 준비된 시작용 프로젝트
- `completed-project`: 공백·근거·변화·다음 행동을 연결한 완성 예시와 조건부 HWPX 샘플

`starter-project`와 `completed-project`는 프로젝트 생성 스크립트에서 다시 만들 수 있도록 유지합니다. 실제 참가자 자료가 아니라 교육용 가상 사례입니다.
