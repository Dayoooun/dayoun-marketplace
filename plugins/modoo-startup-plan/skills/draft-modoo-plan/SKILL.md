# 평가기준형 사업계획 초안

## 사전 조건

- 회사사실표에서 사실·가정·계획이 구분되어 있어야 한다.
- 증거원장에 사용할 수 있는 근거가 있어야 한다.
- 실제 제공된 양식과 평가기준이 일반 참조보다 우선한다.

## 절차

1. 실제 양식의 항목과 평가기준을 대응시킨다.
2. 공식 배점이 공개되지 않았으면 임의 점수를 공식 배점처럼 쓰지 않는다.
3. 문제 → 목표고객 → 기존대안의 한계 → 해결책 → 차별성 → 기대효과 → 시장성 → 구현·검증계획 순으로 논리를 연결한다.
4. 회사 사실과 정량 주장에는 증거 ID를 임시로 붙인다.
5. 근거가 없으면 자연스럽게 꾸미지 말고 {확인필요: 항목}으로 남긴다.
6. 현재 보유 역량과 향후 계획을 같은 시제로 쓰지 않는다.
7. 05. 작성초안/핵심초안.md에 초안을 저장한다.
8. HWPX 스캔으로 확보한 플레이스홀더만 03. 사업계획서양식/placeholder-values.json에 채운다. 필드명을 추측해 새로 만들지 않는다.

## 모두의 창업 일반·기술트랙 기본 관점

- 도전의 진정성: 문제의식, 해결 의지, 신청·개발 배경
- 사회적 가치: 독창성·차별성, 기대효과
- 아이디어 구체성: 구체성, 시장성, 사업화·실현 가능성

부산대 후속 양식과 내부 평가표가 제공되면 그 기준으로 교체한다. 세부 근거는 references/evaluation-map.md를 읽는다.
