# 창업지원 사업계획 공통 평가 정렬

실제 프로그램프로필·공고·평가표·작성요령을 먼저 읽는다. 아래 항목은 공식 기준이 없을 때 질문을 정리하기 위한 공통 관점이며 공식 배점이 아니다.

| 공통 관점 | 확인 질문 | 근거 예시 |
|---|---|---|
| 문제와 진정성 | 누가 어떤 상황에서 문제를 겪으며, 창업자가 왜 이 문제를 해결하려는가 | 문제 발견 경험, 고객 기록 |
| 고객검증 | 고객이 현재 쓰는 대안과 불편을 실제 자료로 확인했는가 | 인터뷰·관찰·사용 기록 |
| 해결책과 차별성 | 해결책이 문제 원인과 연결되고 비교 대상과 차이가 구체적인가 | 대안 비교, 기능 검증 |
| 시장성과 지속성 | 목표고객 범위·지불주체·수익구조에 근거가 있는가 | 공식 통계, 가격·비용 자료 |
| 실행 가능성 | 현재 자원으로 무엇을 언제 어떻게 검증할 것인가 | MVP, 담당, 기한, 완료 증거 |
| 기대효과 | 누구에게 어떤 변화가 생기며 어떻게 측정할 것인가 | 전후 지표, 검증계획 |

## 적용 순서

1. 프로그램프로필에서 공식 평가기준 출처를 확인한다.
2. 공식 문구를 R001 형식 criterion_id로 옮긴다.
3. 양식 항목과 평가기준을 요구사항추적표에서 연결한다.
4. 공식 배점이 없으면 점수를 만들지 않는다.
5. 프로그램명·트랙·마감·수정 가능 여부를 확인하지 못하면 unknown으로 유지한다.

특정 운영기관의 기준은 program_pack이 일치하고 현재 공식 원문을 사용자가 제공했을 때만 추가한다.
