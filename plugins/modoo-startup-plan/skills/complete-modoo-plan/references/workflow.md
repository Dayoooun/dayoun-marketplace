# 전체 워크플로

| 단계 | 입력 | 출력 | 통과 기준 |
|---|---|---|---|
| 1. 준비 | 프로젝트 경로, 트랙 | 표준 폴더, 상태표 | 원본 보관 위치 존재 |
| 2. 사실정리 | 회사자료 | 회사사실표, 누락정보 | 사실·가정·계획 구분 |
| 3. 기준정리 | 공고, 평가표, 양식 | 제출요건표, 평가기준표 | 원문 위치 기록 |
| 4. 조사 | 조사질문 | 증거원장, 경쟁대안표 | 출처·기준일·단위 기록 |
| 5. 초안 | 사실표, 증거원장 | 핵심 초안, 치환값 | 주장과 근거 연결 |
| 6. 검토 | 초안, 원문 | PASS/WARN/BLOCK 표 | BLOCK 0건 |
| 7. HWPX | 작업용 HWPX, 치환값 | 새 HWPX, 치환로그 | 구조 정상, 미치환 0건 |

## 상태 규칙

- PASS: 근거와 문장이 일치하고 바로 사용할 수 있음
- WARN: 합리적이지만 사용자 확인 또는 표현 완화가 필요함
- BLOCK: 허위 가능성, 공식 요구 누락, 개인정보, 수치 충돌, 미치환 항목처럼 다음 단계로 넘기면 안 됨

## 2시간 수업 범위

전체 문서 대필을 목표로 하지 않는다. 핵심 항목 하나를 자료정리 → 근거조사 → 초안 → 검토 → HWPX 반영까지 완주하고 나머지 항목은 같은 방식으로 반복한다.
