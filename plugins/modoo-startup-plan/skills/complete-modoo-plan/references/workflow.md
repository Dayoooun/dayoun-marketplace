# 전체 워크플로

| 단계 | 입력 | 출력 | 통과 기준 |
|---|---|---|---|
| 0. 최소 입력 | 아이디어, 고객, 사용상황 | 첫 질문의 답, 공고 보유 여부 | 초보자 질문 1개 완료 |
| 1. 준비 | 프로젝트 경로, 프로그램프로필, 모드 | 폴더, 사전점검, 입력자료목록 | 실습 경로와 공유등급 확인 |
| 2. 범위·기준 | 제출본, 공고, 평가표 | 실습범위카드, 공백진단표 | 한 공백·한 질문·한 주장 확정 |
| 3. 사실정리 | 창업자·팀·아이디어 자료 | F001 계열 회사사실표, 누락정보 | 사실·가정·계획 구분 |
| 4. 조사 | 선택한 핵심 주장 | 증거원장, 검증활동기록 | C001, 출처·기준일·한계·다음 검증 기록 |
| 5. 변화기록 | 제출본 생각, 새 근거 | 멘토링변화기록 | 유지·수정·보류와 이유 확정 |
| 6. 실행·IR | 공백, 근거, 결정 | 다음공식마감실행카드 | 행동·담당·기한·증빙·1분 IR 연결 |
| 7. 콘텐츠 검토·승인 | 네 결과물, 원문, 검토 범위 | 콘텐츠검토, content-lock | 범위 내 분모 명시, RUN_COMPLETE, BLOCK 0, 사용자 승인 |
| 8. 조건부 HWPX | 주석 HWPX, 승인값 | 새 HWPX 또는 수동 매핑표 | 허용 조건 확인, 0개 치환 방지 |
| 9. 조건부 산출물 검토 | HWPX, 로그 | 산출물검토, release-manifest | FULL / DRY_RUN / FALLBACK 구분 |

## 상태 규칙

- PASS: 해당 검토 기준에서 근거와 문장이 일치함. 운영기관 제출 가능을 자동 의미하지 않음
- WARN: 합리적이지만 사용자 확인 또는 표현 완화가 필요함
- BLOCK: 허위 가능성, 공식 요구 누락, 개인정보, 수치 충돌, 미치환 항목처럼 다음 단계로 넘기면 안 됨

## 2시간 수업 범위

전체 문서 대필이나 HWPX 자동화를 필수 목표로 하지 않는다. 제출본 보존 → 공백진단표 → 검증활동기록 → 멘토링변화기록 → 다음공식마감실행카드까지 완주한다. HWPX는 수정 허용과 양식 사전 검증이 확인된 경우에만 선택한다.
