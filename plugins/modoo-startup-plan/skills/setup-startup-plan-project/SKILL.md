# 사업계획서 프로젝트 만들기

## 절차

1. 사용자가 원하는 프로젝트 경로와 트랙을 확인한다. 트랙이 불명확하면 unknown을 사용하고 확인필요로 남긴다.
2. scripts/create_project.py를 실행한다.

~~~powershell
python scripts/create_project.py --path "C:\작업\모두의창업_사업계획서" --track unknown
~~~

3. 생성 결과를 확인하고 00. 시작하기/프로젝트상태.md를 읽는다.
4. 사용자가 제공한 파일은 복사본을 해당 폴더에 둔다.
   - 회사·대표·아이템 자료: 01. 회사내용/공유가능 원본
   - 공고·평가표·작성요령: 02. 공고문 및 평가지표/원본
   - 원본 HWP: 03. 사업계획서양식/원본 HWP 보관
   - 한글에서 저장한 작업용 HWPX: 03. 사업계획서양식/작업용 HWPX
5. 99. 원본백업은 수정하지 않는다.
6. 기존 파일은 사용자가 명시적으로 요청하지 않는 한 덮어쓰지 않는다.

폴더별 역할은 references/project-layout.md를 읽는다.
