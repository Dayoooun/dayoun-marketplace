# 프로젝트 폴더

~~~text
모두의창업_사업계획서/
├─ 00. 시작하기/
├─ 01. 회사내용/
│  └─ 공유가능 원본/
├─ 02. 공고문 및 평가지표/
│  └─ 원본/
├─ 03. 사업계획서양식/
│  ├─ 원본 HWP 보관/
│  └─ 작업용 HWPX/
├─ 04. 시장조사 리서치/
│  └─ 출처원문/
├─ 05. 작성초안/
├─ 06. 검토결과/
├─ 07. 최종본/
└─ 99. 원본백업/
~~~

## 운영 규칙

- 원본은 99. 원본백업과 원본 전용 폴더에 보관한다.
- AI 출력은 먼저 05. 작성초안에 저장한다.
- 검토표는 06. 검토결과에 저장한다.
- BLOCK이 0건이고 HWPX 열기 확인까지 끝난 파일만 07. 최종본에 둔다.
- 파일명은 YYYYMMDD_문서명_v01 형식을 권장한다.
