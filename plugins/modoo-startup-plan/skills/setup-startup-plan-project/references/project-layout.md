## 운영 규칙

- 원본은 99. 원본백업과 원본 전용 폴더에 보관한다.
- 제출본은 기준점으로 보존하고 공백진단표·검증활동기록·멘토링변화기록·다음공식마감실행카드를 기본 결과물로 만든다.
- AI가 제안한 문안은 먼저 05. 작성초안에 저장한다.
- 검토표는 06. 검토결과에 저장한다.
- HWPX는 수정 허용과 실제 양식 사전 검증이 확인된 경우에만 선택한다.
- 선택 HWPX 결과는 BLOCK이 0건이고 한글 육안검수까지 끝났을 때만 FULL로 기록한다.
- FULL / DRY_RUN / FALLBACK과 NOT_RUN 검토상태는 release-manifest.md에 기록한다.
- 파일명은 YYYYMMDD_문서명_v01 형식을 권장한다.
