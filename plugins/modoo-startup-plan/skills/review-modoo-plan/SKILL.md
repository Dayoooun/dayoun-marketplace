# 제출 전 검토

## 입력

- 회사사실표
- 공고·평가기준 원문
- 증거원장
- 핵심초안
- placeholder-values.json
- 생성된 HWPX와 replacement-log.csv

## 검토 방식

각 항목을 PASS, WARN, BLOCK으로 분류한다.

### BLOCK

- 실적·매출·고객·계약·특허·인증을 근거 없이 단정
- 정량 주장에 출처·기준일·단위가 없음
- 현재 사실과 향후 계획이 혼재
- 공고의 필수 항목 누락
- 개인정보나 비공개정보 노출
- 원문 장문 복사 또는 타인 아이디어 도용 위험
- 미치환 중괄호 존재
- HWPX 구조검증 실패

### WARN

- 분석과 사실의 경계가 흐림
- 과장 표현
- 경쟁대안 비교 근거 부족
- 목표고객·수익모델·검증계획이 추상적
- 공식 배점이 아닌 점수를 공식처럼 표시
- 동일 수치의 기준연도·단위 불일치

## 출력

06. 검토결과/최종검토.md에 다음을 기록한다.

1. 요약: PASS/WARN/BLOCK 건수
2. BLOCK 수정 목록
3. WARN 개선 목록
4. 평가기준별 누락
5. 문장별 근거 ID
6. 미치환 항목
7. 다음 행동 3개

BLOCK이 0건이 되기 전에는 제출 가능하다고 말하지 않는다. 세부 체크표는 references/review-rubric.md를 읽는다.
