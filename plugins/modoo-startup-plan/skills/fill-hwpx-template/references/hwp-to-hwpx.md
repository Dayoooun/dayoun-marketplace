# HWP를 HWPX로 준비하기

1. 한글에서 원본 HWP를 연다.
2. 파일 → 다른 이름으로 저장을 선택한다.
3. 파일 형식에서 HWPX를 선택한다.
4. 03. 사업계획서양식/작업용 HWPX에 저장한다.
5. 원본 HWP는 03. 사업계획서양식/원본 HWP 보관과 99. 원본백업에 보관한다.

## 플레이스홀더 규칙

- 한 항목은 {회사명}, {문제정의}, {시장근거}처럼 중괄호로 표시한다.
- 긴 여러 줄 내용을 넣을 플레이스홀더는 문단에 단독으로 둔다.
- 표 안에서도 사용할 수 있으나 복잡한 병합 셀은 결과를 반드시 육안 확인한다.
- 플레이스홀더가 여러 XML 텍스트 조각으로 분리되면 자동 스캔되지 않을 수 있다. 이 경우 한글에서 플레이스홀더를 다시 한 번 입력한다.

## 검증 한계

스크립트는 ZIP 구조, 필수 파일, XML 문법, 미치환 항목을 확인한다. 한글의 실제 레이아웃과 페이지 넘김은 한컴오피스에서 직접 확인해야 한다.
