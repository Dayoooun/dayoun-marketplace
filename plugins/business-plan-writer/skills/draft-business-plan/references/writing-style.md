# 사업계획서 문체와 서식 기준

## 적용 순서

1. 최신 공식 양식·작성요령·글자 수 제한을 가장 먼저 따른다.
2. 사용자가 승인한 기존 문서나 표현 예시가 있으면 그 형식을 이어간다.
3. 별도 기준이 없을 때만 아래 기본값을 사용한다.

작성 전에 적용할 문체, 번호 체계, 목록, 들여쓰기, 표와 단위 기준을 짧게 정한다. 초안 중간에 기준을 임의로 바꾸지 않는다.

## 문체와 문단

- 공식 지침이 없으면 `~한다`, `~이다` 문체를 기본으로 사용하고, `~합니다` 문체와 혼용하지 않는다.
- 한 문단에 하나의 핵심만 담는다. 첫 문장에 답을 쓰고 뒤에 근거, 실행 방법, 의미를 이어 쓴다.
- 주어와 행동을 분명하게 쓰고, 한 문장에 서로 다른 주장을 여러 개 엮지 않는다.
- 숫자·일정·대상·행동이 있는 구체적인 표현을 사용하고, `효과적`, `혁신적`, `다양한` 같은 모호한 수식어는 근거 없이 쓰지 않는다.
- 목록은 명사형이면 명사형, 완전한 문장이면 완전한 문장으로 맞추고 문장부호도 같게 적용한다.

## 주장과 출처 추적

- 초안과 승인 JSON의 모든 주장 문단 끝에는 `[E001 | 기관명, {발표연도}]`, `[U001 | 사용자 제공자료, {기록연도}]`, `[H001 | 검증가설]`, `[P001 | 실행계획]` 중 하나 이상을 붙인다.
- `E`는 외부 근거, `U`는 사용자 제공 사실, `H`는 검증가설, `P`는 앞으로 할 계획이다.
- E/U의 `|` 뒤에는 `출처명, YYYY`를 적는다. 연도는 `근거목록.csv`의 발표일·기록일·기준일·확인일에서 확인한 값과 같아야 한다.
- 각 ID는 `00. 시작하기/근거목록.csv`의 동일한 `evidence_id`로 기관·자료명·URL·기준일·한계까지 역추적한다.
- 최종 HWPX에는 내부 ID 대신 `(기관명, 연도)` 형식만 보인다. 여러 근거는 `(기관명, 연도; 기관명, 연도)`로 묶는다.
- 한 문단에 서로 다른 출처가 필요한 주장을 섞지 않는다. 근거가 다르면 문단을 나눈다.
- 출처가 없는 내용은 사실처럼 쓰지 않고 `[H001 | 검증가설]`이나 `{확인필요: 내용}`으로 남긴다.
- 회사명·성명·날짜처럼 주장하지 않는 식별 라벨만 승인 값 JSON의 `_claim_free`에 키와 사유를 명시한다.

## 개조식과 내어쓰기 기본

HWPX 답변 셀은 길이와 공식 서술형 여부에 관계없이 개조식으로 작성한다. 승인값이 산문이면
filler가 `o 핵심내용 → - 주장`으로 자동 정규화하고 대상 플레이스홀더를 사용자에게 알린다.

```text
o 핵심항목
- 확인된 사실, 근거와 기준일
- 실행 방법 또는 다음 검증

o 다음 핵심항목
- 판단 기준과 후속 행동
```

- `o 핵심항목`은 한 줄 제목으로 쓰고 굵게 표시한다.
- `- 세부내용`은 한 문단에 하나의 주장만 담는다.
- 두 줄 이상 자동 줄 바꿈될 때 둘째 줄은 하이픈 뒤 본문 시작선에 맞춘 내어쓰기를 적용한다.
- 공백·탭·전각 공백으로 모양을 흉내 내지 않고 HWPX 문단의 `paraPr` margin을 사용한다.
- 항목 사이의 빈 줄은 넣지 않는다. 문단 위·아래 간격은 문단 스타일로 조정한다.
- 개조식 예외 플래그는 두지 않는다. 공식 양식의 질문과 분량은 지키되 답변 구조는 같은 개조식과 내어쓰기로 통일한다.

## 번호 체계와 들여쓰기

- 공식 양식의 장·절 번호와 순서를 유지한다. 기준이 없으면 `1. 장` → `1.1 절` → `(1) 항목` 순으로 최대 3단계만 사용한다.
- 중간 번호를 건너뛰지 않고, 같은 단계에서 서로 다른 번호 형식을 섞지 않는다.
- 들여쓰기는 공백이나 탭을 반복해 만들지 말고 문서의 문단·목록 스타일을 사용한다.
- 같은 단계의 목록은 같은 들여쓰기를 적용하고, 두 줄 이상으로 이어지면 둘째 줄을 본문의 시작 위치에 맞춘다.
- 본문 단락에 불필요한 줄 바꿈과 빈 줄을 추가해 분량을 늘리지 않는다.

## 표와 숫자

- 표는 비교, 일정, 예산처럼 반복되는 항목을 한눈에 볼 필요가 있을 때만 사용한다.
- 한 열에는 하나의 기준만 두고, 표 제목·머릿글·단위·기준일을 분명하게 쓴다.
- 같은 열의 숫자는 동일한 단위와 자릿수를 사용하고, 합계·비율·원단위의 계산 기준을 표 아래에 적는다.
- 표 안에 긴 서술을 억지로 넣지 말고, 핵심값은 표에 두고 설명은 본문으로 분리한다.
- 외부 사실과 숫자를 사용한 표에는 출처와 기준일을 연결한다.

## HWPX에 반영할 때

- 승인된 `o`·`○`·`□` 핵심항목과 `-`·`•`·`▪` 세부내용 접두사는 filler가 문단 역할로 해석하는 의미 표지다. 그 밖의 마크다운 기호는 넣지 않으며 공식 양식·사용자 서식 요구가 생성 기본값보다 우선한다.
- 공백·탭·줄 바꿈으로 들여쓰기나 페이지 배치를 임의로 만들지 않는다.
- 입력 후 표 너비, 행 높이, 자동 줄 바꿈, 글자 겹침, 문단 번호, 페이지 넘김을 한글 화면에서 확인한다.
