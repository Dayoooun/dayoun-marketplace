# 참가자 한 장 빠른 시작

아이디어 한 문장만 있다면 파일을 만들기 전에 먼저 답합니다.

> 이 아이디어는 누가, 어떤 상황에서, 어떤 문제를 겪을 때 사용하나요? 모르겠다면 “아직 모름”이라고 답합니다.

## 사업계획서에서 먼저 보는 다섯 가지

1. 문제–고객–해결–차별성–수익방법–실행계획이 연결되는가
2. 시장·고객·성과 주장에 출처 또는 실제 기록이 있는가
3. 누가, 언제, 무엇을 검증할지 구체적인가
4. 공고와 평가기준이 묻는 질문에 직접 답하는가
5. 확인된 사실, 가정, 앞으로의 계획이 구분되는가

## 같은 일을 하는 방식이 이렇게 달라집니다

| 작업 | 기존 방식 | 에이전트 방식 | 내가 확인할 것 |
|---|---|---|---|
| 자료·평가기준 정리 | 파일과 문서를 직접 찾아 메모 | 자료 목록을 만들고 평가기준과 현재 내용을 연결 | 최신 공식 원문 |
| 조사·근거 기록 | 여러 검색창의 내용을 복사 | 질문 하나의 출처·기준일·한계를 함께 기록 | 원문과 주장 일치 여부 |
| 초안·팩트체크 | 빈 문서나 이전 문장을 고친 뒤 마지막에 재검토 | 확인된 사실로 초안을 만들고 누락·충돌 표시 | 최종 문장과 사업 판단 |
| HWPX·다음 행동 | 원본에 붙여넣고 회의 메모를 따로 관리 | 승인한 내용만 복사본에 반영하고 실행카드로 연결 | 화면 검수, 담당자와 기한 |

에이전트는 정리·비교·기록을 돕습니다. 사실 확인과 최종 결정은 내가 합니다.

- 내가 알고 있는 정보: 회사·팀·제품·고객에 대해 제공한 내용
- 확인이 필요한 내용: 자료 조사나 고객 기록으로 확인할 시장·고객·경쟁 관련 설명

오늘은 가장 중요한 확인 내용 하나만 골라 조사, 수정, 다음 행동까지 같은 내용으로 이어갑니다.

## 에이전틱하게 해결하는 연결선

```text
가장 중요한 부족한 점 1개
→ 관련 내용의 근거 확인
→ 유지·수정·보류 결정
→ 다음 행동 1개
→ 1분 설명
```

AI에게 문서 전체를 한 번에 맡기지 않습니다. 목표를 작은 작업으로 나누고, 자료를 확인하고, 중간 결과를 검토한 뒤 다음 작업으로 이어갑니다.

## 오늘 만드는 네 가지

1. 평가 공백 한 개
2. 근거·고객검증 기록 한 건
3. 유지·수정·보류 변화기록 한 건
4. 다음 실행카드와 1분 설명

원본과 작업용 복사본을 서로 다른 파일로 보관합니다.

## 내 실습 경로

- Green: Codex·Claude Code·Antigravity 중 한 에이전트와 Python·웹 사용 가능 → 개인자료와 파일형 확장
- Yellow: 일반 채팅형 AI 또는 일부 에이전트 기능만 가능 → 스타터 프로젝트의 작업표와 오프라인 근거팩
- Red: 도구·사용량 문제 → 짝 실습과 완성 예시 검토

## GPT·Gemini·Claude 공통 요청 1 · 공백 진단

```text
아래 사업계획 내용과 공고·평가기준을 비교해줘.
이미 잘된 점을 늘어놓지 말고, 다음 단계에서 가장 먼저 확인할 공백 1개만 골라줘.
공식 문서에 없는 배점은 만들지 말고 다음 표로 작성해줘.

평가기준 | 현재 내용 | 부족한 근거 | 확인 질문 | 다음 행동
```

## 공통 요청 2 · 근거 기록

```text
선택한 주장 1개와 제공된 출처를 검토해줘.
출처가 실제로 말하는 범위를 넘겨 해석하지 말고 다음 형식으로 정리해줘.

확인할 내용 | 출처·기준일 | 확인한 결과 | 말할 수 없는 범위 | 다음 확인
```

## 공통 요청 3 · 변화기록

```text
기존 생각과 새 근거·피드백을 비교해줘.
결론을 대신 정하지 말고 선택지와 이유를 보여줘.

변경 전 | 새 근거·피드백 | 유지·수정·보류 | 결정 이유 | 다음 검증
```

## 공통 요청 4 · 실행카드와 1분 설명

```text
다음에 실행할 행동 1개를 정리해줘.
담당자, 기한, 완료 기준, 남길 증빙을 포함해줘.
이어서 문제–고객–해결–차별성–다음 검증 순서의 1분 설명 초안을 만들어줘.
확인되지 않은 실적과 시장 수치는 새로 만들지 마.
```

## 에이전트 확장

Codex·Claude Code·Antigravity에서 스킬을 읽을 수 있는 참가자는 새 작업에서 다음처럼 요청합니다.

```text
complete-business-plan 스킬을 사용해 DEMO 또는 PARTIAL 모드로 시작해줘.
원본 자료는 보존하고, 작업범위에서 보완점 하나와 확인할 내용 하나만 선택하도록 안내해줘.
```

설치와 폴더 위치는 [멀티 프로바이더 안내](07-multi-provider-guide.md)를 확인합니다. 일반 채팅형 AI에서는 위의 공통 요청 1~4를 순서대로 사용합니다.

## 종료 전 본인 확인

- [ ] 부족한 점, 조사 결과, 결정, 다음 행동, 1분 설명이 같은 이야기로 연결된다.
- [ ] 내 아이디어와 최종 결정은 내가 작성·승인했다.
- [ ] 출처 원문과 기준일을 직접 확인했다.
- [ ] 허위 실적·과장·출처 없는 수치를 제거했다.
- [ ] 개인정보·영업비밀을 넣지 않았다.
- [ ] 원본과 작업용 복사본을 구분했다.
