# 완성 예시 프로젝트

가상 회사 `모두랩`의 제출본 기준점 → 공백진단표 → 검증·활동 기록 → 멘토링 변화기록 → 다음 공식 마감 실행카드를 연결한 교육용 예시입니다.

가상 회사·인터뷰·대안 정보는 실제 제출자료나 시장근거로 사용하면 안 됩니다. `demo-filled.hwpx`는 필수 결과물이 아니라, 수정 허용과 양식 사전 검증이 확인된 경우의 선택 트랙을 보여주는 교육용 문서입니다.

회사 내부 입력은 F001 계열로, 교육 중 검증하는 핵심 주장은 C001 하나로 분리했습니다. 콘텐츠 검토의 100%는 EDUCATION_SINGLE_CLAIM 범위 안에서만 의미하며 전체 제출본 통과를 뜻하지 않습니다.
