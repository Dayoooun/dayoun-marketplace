# 오프라인 근거팩 사용법

이 폴더는 인터넷이나 웹 검색 권한이 없을 때 사용하는 교육용 대체자료입니다.

1. `01-official-program-criteria.md`에서 공식 평가 관점을 확인합니다.
2. `02-fictional-company-brief.md`에서 확인된 회사 사실과 계획을 구분합니다.
3. `03-fictional-customer-notes.md`에서 가장 중요한 고객 주장 하나를 선택합니다.
4. `04-claim-plan.csv`에 채택·보류·사용금지를 표시합니다.
5. `05-fictional-alternatives.csv`를 사용해 기존 대안과 차이를 한 문장으로 정리합니다.

가상 회사·인터뷰·대안 자료는 작업 방법을 연습하기 위한 것으로 실제 사업계획서의 사실이나 시장근거로 사용하면 안 됩니다.
