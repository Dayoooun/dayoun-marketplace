# 강사용 운영 가이드 초안

## 수업 전 준비

- 실제 양식의 HWP·HWPX 두 버전 확보
- 중괄호 플레이스홀더가 들어간 실습용 HWPX와 완성본 준비
- 정상 단계별 산출물 7개를 강사 PC에 보관
- dayoun 마켓플레이스 로컬 설치와 GitHub 설치 모두 시험
- 와이파이 실패용 시장자료 PDF·통계표·경쟁사 자료 준비
- 참가자 상태를 초록/노랑/빨강으로 표시할 조교 체크표 준비

## 체크포인트

| 시점 | 전원 확인 기준 | 미달 시 조치 |
|---|---|---|
| 25분 | 프로젝트 폴더 생성 | 완성 폴더 ZIP 제공 |
| 40분 | 회사사실표·평가기준표 생성 | 샘플 회사자료로 전환 |
| 65분 | 출처가 있는 근거 3개 | 오프라인 근거팩 사용 |
| 90분 | 핵심 초안 1개 | 강사 제공 초안에서 검토 실습 |
| 110분 | HWPX 또는 치환표 생성 | Markdown 치환표로 대체 |

## 장애 대응

- 플러그인이 보이지 않음: 새 작업 시작 → 앱 새로고침 → 로컬 스킬 경로로 전환
- 사용량 한도: 2인 1조 또는 강사 화면으로 계속 진행
- 인터넷 실패: 04_시장조사_리서치/출처원문의 오프라인 자료 사용
- HWPX 실패: 원본을 건드리지 않고 placeholder-values.json과 Markdown 초안까지만 완성
- 개인 자료 부족: 제공된 샘플 회사와 실습용 HWPX 사용

## 강의 멘트 핵심

- “AI가 내용을 만들어 주는 수업이 아니라, 근거를 정리하고 빠뜨린 질문을 찾아 주는 수업입니다.”
- “근거가 없으면 자연스럽게 꾸미지 않고 확인필요로 남깁니다.”
- “오늘은 전체 문서가 아니라 한 항목을 끝까지 완주합니다.”
- “원본 HWPX는 수정하지 않습니다. 결과물은 항상 새 파일입니다.”

## 운영상 주의

8월 14일 제출 마감이 8월 19일 강의보다 먼저입니다. 제출 이후 수정 가능 여부가 확인되지 않으면 결과물을 제출본이라고 부르지 말고 사업계획 고도화본, 활동 결과물, IR 준비자료로 안내합니다.
