# 강사용 운영 가이드

## 수업 목표

이 강의는 8월 14일 제출 뒤인 8월 19일에 진행합니다. 수정 가능 여부가 확인되지 않는 한 제출본을 읽기 전용 기준점으로 보존하고, 선정 이후의 사업계획 고도화·활동기록·멘토링·IR 준비로 안내합니다.

모든 참가자의 필수 성공 기준은 다음 네 가지입니다.

1. 부산대 평가기준에서 우선 보완할 공백 한 개를 선택한다.
2. 핵심 주장 하나를 `C001`로 기록하고 공식 출처 또는 기존 고객근거 한 개를 연결한다.
3. 제출 당시 생각과 새 근거를 비교해 유지·수정·보류 변화기록을 남긴다.
4. 다음 공식 마감 실행카드와 1분 IR 핵심 메시지를 만든다.

개인 HWPX 생성은 수정 허용·실제 양식·한글 환경이 모두 확인된 Green 참가자의 선택 목표입니다.

## 강의 중심선

첫 10분에는 AI 기능보다 좋은 사업계획서의 기준을 먼저 설명합니다.

1. 문제–고객–해결–차별성–수익방법–실행계획이 연결되는가
2. 시장·고객·성과 주장에 출처 또는 실제 기록이 있는가
3. 담당자·기한·완료 증거가 구체적인가
4. 공고와 평가기준이 묻는 질문에 직접 답하는가
5. 확인된 사실·가정·향후 계획이 구분되는가

이후 모든 실습에서 `평가 공백 1개 → C001 근거 → 유지·수정·보류 결정 → 다음 행동 → 1분 IR` 연결을 유지합니다. 앞 단계의 근거가 바뀌면 뒤 단계의 결정과 설명도 함께 바꾸도록 안내합니다.

## 수업 전 준비

- 실제 생성 스크립트와 같은 `00. 시작하기`~`99. 원본백업` 스타터 프로젝트
- 네 가지 필수 산출물이 채워진 완성 예시
- 공식 프로그램 기준과 교육용 가상자료를 포함한 오프라인 근거팩
- GPT 공통 프롬프트 카드와 Codex 확장 카드
- 중괄호 플레이스홀더가 들어간 교육용 HWPX, 완성본, 수동 치환표
- Green·Yellow·Red 참가자 상태표와 인쇄 워크시트
- dayoun 설치, Python, GitHub, 로컬 ZIP 경로를 별도 Windows PC에서 검증

## 120분 운영표

| 시간 | 운영 | 필수 확인 |
|---|---|---|
| 00~10분 | 좋은 사업계획서의 기준과 에이전틱 해결법 | 핵심 5가지와 한 줄 연결 이해 |
| 10~20분 | 제출본 기준점 보존, Green·Yellow·Red 확정 | 원본과 작업본 분리 |
| 20~40분 | 부산대 평가 공백 한 개 선택 | 공백진단표 |
| 40~60분 | 주장 C001과 근거 한 개 확인 | 출처·기준일·한계 |
| 60~80분 | 유지·수정·보류 변화기록 | 결정과 이유 |
| 80~100분 | 다음 공식 마감 실행카드·1분 IR | 담당·기한·증빙·핵심 메시지 |

## Green·Yellow·Red 전환 규칙

| 경로 | 판정 | 즉시 제공할 것 |
|---|---|---|
| Green | GPT·Codex·Python·웹이 정상 | 개인 프로젝트·Codex 확장 카드 |
| Yellow | GPT는 되지만 나머지 중 하나 실패 | 스타터 프로젝트·오프라인 근거팩·GPT 카드 |
| Red | 로그인·사용량 문제로 개인 AI 사용 불가 | 짝 배정·인쇄 워크시트·완성 예시 |

- 한 문제를 5분 넘게 해결하지 않습니다.
- 20분 이후에는 재설치하지 않고 Yellow 또는 Red로 고정합니다.
- 2인 1조에서는 조작자와 근거·표현 검토자 역할을 중간에 바꿉니다.
- 어느 경로든 네 가지 필수 산출물의 질문과 품질 기준은 같습니다.

## 강의 멘트 핵심

- “GPT가 기본 경로이고 Codex는 같은 판단을 파일 작업으로 확장합니다.”
- “오늘은 다섯 개를 조사하지 않고 가장 중요한 주장 하나만 확인합니다.”
- “AI 문장은 참가자가 고치고 승인한 뒤에만 결과물로 사용합니다.”
- “제출본 원본은 수정하지 않고, 무엇을 확인해 생각이 어떻게 바뀌었는지 남깁니다.”
- “개인 HWPX 자동화는 선택이고 네 가지 활동 결과물이 필수입니다.”

## 종료 기록

- 실제 경로: Green / Yellow / Red
- 공백진단표: 완료 / 미완료
- C001 근거와 한계: 완료 / 미완료
- 변화기록: 유지 / 수정 / 보류 / 미완료
- 실행카드와 1분 IR: 완료 / 미완료

결과물은 제출 가능으로 단정하지 않습니다. 활동보고서·멘토링·IR 등 실제 용도와 다음 공식 마감을 참가자와 확인해 기록합니다.
