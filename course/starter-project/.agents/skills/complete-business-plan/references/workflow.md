# 범용 사업계획서 작업 흐름

사용자는 이 표를 지시할 필요가 없다. 에이전트가 자연어 요청에서 최종 산출물과 고정
조건을 추출하고 아래 단계를 연결한다. 공식 자료·양식·회사·아이디어 분석은 먼저 실행하고,
외부 조사는 방향 인터뷰가 확정된 뒤 시작한다. 사용자 결정이 필요한 단계에는 평가기준상
권장안과 대안을 제시한다.

| 단계 | 확인할 것 | 기본 결과물 | 통과 기준 |
|---|---|---|---|
| 1. 공고·평가·지침·양식 분석 | 자격, 지원, 일정, 제출, 평가, 작성 제한, 수정공고 | 공고분석표, 요구사항-양식-평가지표 연결표 | 모든 공식 요구에 원문 위치·기준일이 연결됨 |
| 2. 회사·사업·아이디어 분석 | 회사·팀·제품·고객·실적·아이디어 | 사업정보표, 사실·가정·계획 구분표 | 사용자 제공 정보와 미확인 정보가 분리됨 |
| 3. 방향 인터뷰·근거 공백·질문 도출 | 목표고객, 문제, 첫 제품·판매 방식, 평가항목별 현재 답변과 부족한 증거 | 방향결정.md, 근거공백표, 조사질문.md | 사용자가 조사 방향을 확인하고 각 질문이 공고 요구 또는 핵심 가정과 연결됨 |
| 4. 시장·고객·경쟁·가격·규제 독립 조사 | 방향 확인 뒤 3단계 질문에 필요한 1차 자료 | 독립조사계획.json, worker별 결과, 독립조사종합.md, 조사기록 | FULL·교육 실습은 독립 worker 3개 이상이며 출처·날짜·단위·한계·실패 범위가 기록됨 |
| 5. 전략·실행·수익구조 설계 | 문제부터 실행·재무·위험까지의 연결 | 이야기 구조표, 실행·수익·위험 계획 | 조사 결과와 활동·예산·성과가 이어짐 |
| 6. 텍스트 초안 작성 | 공식 평가항목·양식 질문·분량 제한 | 사업계획서초안.md, 변경기록 | 근거 없는 내용은 확인 필요로 표시됨 |
| 7. 검토·수정·승인 | 누락, 논리, 근거, 숫자, 표현, 공개 범위 | 검토표, 수정본, 문안승인.md | 범위 내 BLOCK이 없고 최종 문안이 승인됨 |
| 8. HWPX 반영 | 승인값, 최신 user-edited canonical 또는 최초 원본, 사용자 디자인 지시, 정보밀도 | canonical receipt, deletion receipt, 디자인 결정표, 새 HWPX, 치환·시각자료 로그 | 최신 사용자 수정본이 source로 잠기고 승인값과 고정 디자인 조건만 반영됨 |
| 9. HWPX 검증 | ZIP/XML, 스타일 배열 순서·참조, 사용자 시각자료 profile, Preview 동기화, 미치환, 표·줄바꿈·페이지 | style/source/preview 검사 결과, PDF/PNG 화면검사 기록 | 사용자 스타일·삭제 의도가 보존되고 구조검사와 실제 렌더 확대검사가 모두 통과함 |
| 10. 발표자료 제작 | 승인된 주장, 청중, 발표시간, Q&A 위험 | deck_brief, content_report, PPTX, 대본, Q&A | 수치·고유명사가 승인 원문과 일치하고 렌더를 육안 확인함 |

## 단계 게이트와 되돌아가기

- 1단계에서 공식 기준을 잠그기 전에는 배점 중심의 초안을 만들지 않는다.
- 2단계 자료 분석과 3단계 방향 확인을 마친 뒤에만 4단계 외부 조사 worker를 시작한다.
- 조사 결과가 아이디어의 핵심 가정을 부정하면 2·3·5단계로 돌아간다.
- 6단계는 텍스트로 작성한다. HWPX 안에서 초안을 고치지 않는다.
- 7단계 승인 뒤에만 8단계 HWPX를 만든다.
- 9단계가 실패하면 승인값·위치표 또는 양식을 고치고 새 버전으로 다시 만든다.
- 10단계는 HWPX 페이지 복사가 아니라 승인된 사업계획서의 발표용 재구성이다.

## 목적별 우선 확인

| 목적 | 우선 기준 |
|---|---|
| 지원사업·공모 | 공식 공고, 평가표, 작성요령, 제출 양식 |
| 투자·IR | 성장 가능성, 시장, 팀, 실적, 자금 사용계획 |
| 사내 검토 | 전략 적합성, 자원, 일정, 손익, 위험 |
| 대출·제안 | 상환·수행 가능성, 계약 조건, 현금흐름, 증빙 |
| 자율 계획 | 독자와 의사결정 목적에 맞춘 필수 장·절 |

공식 자료가 있으면 일반 기준보다 항상 우선한다. 공식 자료가 없으면 그 사실을 밝히고 일반 기준을 질문 목록으로만 사용한다.
