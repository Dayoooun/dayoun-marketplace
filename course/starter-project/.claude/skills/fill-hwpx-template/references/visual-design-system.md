# HWPX 시각자료 디자인·배치 기준

## 우선순위

최신 공식 양식과 사용자의 명시적 요구가 항상 우선이다. 별도 요구가 없을 때만 이 문서의 공통 기본값을 적용한다. 시각자료를 맞추기 위해 원본 쪽 크기·여백·머리말·꼬리말·제본·쪽 테두리를 바꾸지 않는다.

## 시각자료를 넣을 때

평가자의 판단을 돕는 문제 구조, 사업모델, 경쟁 비교, 실행 로드맵, 예산, KPI, 근거 흐름을 우선 검토한다. 문장을 반복하는 장식 이미지, 근거 없는 수치, 공식 양식의 질문과 무관한 이미지는 추가하지 않는다.

시각자료 명세에는 다음 값을 모두 기록한다.

```text
시각자료 종류 / 핵심 메시지 / 근거 / 삽입할 표 셀 /
앞 문단 / 뒤 문단 / 짧은 캡션
```

문단 번호나 답변 셀 끝을 위치 기준으로 사용하지 않는다. 내용이 바뀌어도 찾을 수 있는 `앞 문단 / 뒤 문단` 문구로 의미상 위치를 고정한다.

```text
o 핵심항목
  - 시각자료가 설명하는 문단

[1열 2행 중첩표: 이미지 / 짧은 캡션]

o 다음 핵심항목
  - 다음 설명문단
```

답변 셀 마지막 일괄 배치는 금지한다.

## 한글 호환 HWPX 구조

시각자료는 관련 외부 표 셀 안에 1열 2행 중첩표로 배치한다.

```text
tc
└─ subList
   └─ p
      └─ run
         └─ tbl
            ├─ tr → tc: 이미지
            └─ tr → tc: 캡션
```

`subList → tbl` 또는 `p → tbl` 직접 삽입은 한글이 중첩표와 이미지를 무시할 수 있으므로 금지한다.

## 검증된 1R 양식 profile

아래 값은 `성명_1R_사업계획서_새양식_시각화반영본 (2).hwpx`에서 실측한 값이다. 다른 양식에 강제로 덮어쓰지 않는다. 다른 양식에서는 원본 표 셀 너비에 맞춰 비례 조정하고 원본 `secPr`을 보존한다.

| 항목 | 1R 실측값 |
|---|---:|
| 중첩표 | 1열 × 2행 |
| 중첩표 너비 | 45,900 HWPUNIT |
| 이미지 표시 너비 | 43,900 HWPUNIT |
| 셀 좌우 여백 | 510 HWPUNIT |
| 셀 위아래 여백 | 220 HWPUNIT |
| 캡션 행 높이 | 1,200 HWPUNIT |
| 캡션 | 12pt, 굵게, 가운데 정렬 |
| 캡션 배경 | #F2F2F2, 얇은 검정 테두리 |

실측한 1R 쪽 설정은 용지 `59528 × 84186`, 좌우 `5669`, 위 `4251`, 아래 `4252`, 머리말·꼬리말 `2834`, 제본 `0 HWPUNIT`이다. 이 수치를 다른 양식의 기본값으로 쓰지 않는다.

## 이미지와 캡션

- 이미지 원본 비율을 유지한다. 표시 너비, 표시 높이, 원본 크기, 클립 영역이 서로 일관돼야 한다.
- 한글이 `image3.PNG`처럼 파일명을 정규화할 수 있으므로 특정 이미지 ID나 파일명을 하드코딩하지 않는다.
- `<img binaryItemIDRef>`, `Contents/content.hpf`의 item, 실제 `BinData` member가 모두 일치해야 한다. manifest ID와 ZIP member 중복, 절대경로·역슬래시·`.`·`..` segment, `BinData/` 밖 이미지 href는 금지한다.
- 캡션은 50자 이내의 `그림 N. 핵심 그림명`만 사용한다.
- 긴 해설, 근거 문장, `자체 구성`, 대시로 이어 붙인 부제는 캡션에서 제거한다.
- 예: `그림 2. 6주 아이디어 고도화 로드맵`

## 타이포그래피와 시각 언어

공식 양식이나 사용자·브랜드 요구가 없을 때만 Pretendard를 기본 한글 글꼴로 사용한다. HWPX 원문 스타일을 임의로 전면 교체하지 않는다. 새로 만드는 설명용 시각자료에는 흰 배경, 밝은 회색 면, 짙은 남회색 본문, 파란 강조색, 얇은 구분선, 충분한 여백의 간결한 정보 디자인을 사용한다. 특정 금융 앱의 로고·고유 화면·상표 요소를 복제하지 않는다.

## 재현 검증

먼저 시각자료 위치 명세 JSON을 만든다.

```json
{
  "visuals": [
    {
      "caption": "그림 2. 6주 아이디어 고도화 로드맵",
      "beforeParagraphContains": "향후 6주 동안",
      "afterParagraphContains": "o 사업 추진·수정·중단 기준",
      "tableWidth": 45900,
      "imageWidth": 43900,
      "cellMargin": {"left": 510, "right": 510, "top": 220, "bottom": 220},
      "captionRowHeight": 1200,
      "captionPointSize": 12,
      "captionBold": true,
      "captionAlign": "CENTER",
      "captionBackground": "#F2F2F2"
    }
  ]
}
```

작업 결과를 검사한다.

```powershell
python "<스킬 루트>\scripts\hwpx_visuals.py" validate "결과.hwpx" --source "원본.hwpx" --spec "visual-placement.approved.json"
```

완료 조건은 다음과 같다.

1. 명세의 모든 시각자료가 한 번씩 존재한다.
2. `tc → subList → p → run → tbl` 계층과 1열 2행 구조가 맞다.
3. 앞 문단과 뒤 문단이 명세와 일치한다.
4. 이미지 참조·manifest·BinData가 일치한다.
5. 캡션 형식·정렬·행 높이·배경이 명세와 일치한다.
6. 원본과 결과의 `secPr` canonical digest가 같다.
7. 한글에서 실제 위치, 비율, 해상도, 캡션, 표·페이지 넘김을 화면으로 확인한다.
