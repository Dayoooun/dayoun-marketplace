# 사업계획서 공통 확인 관점

이 표는 공식 평가표가 없을 때 누락을 찾는 질문 목록이다. 공식 배점이나 특정 기관의 평가기준이 아니다.

| 관점 | 확인 질문 | 근거 예시 |
|---|---|---|
| 목적과 요약 | 누가 무엇을 결정하도록 만드는 문서인가 | 독자, 의사결정, 한 문장 요약 |
| 문제와 고객 | 누가 어떤 상황에서 어떤 문제를 겪는가 | 인터뷰, 관찰, 문의 기록 |
| 해결책과 차별점 | 문제 원인과 해결 방식이 이어지고 기존 대안과 차이가 구체적인가 | 제품 자료, 대안 비교, 시험 결과 |
| 시장과 경쟁 | 목표고객 범위와 시장 변화, 경쟁 대안을 근거로 설명했는가 | 공식 통계, 공시, 가격표 |
| 수익 구조 | 누가 무엇에 얼마를 지불하고 비용은 어떻게 생기는가 | 가격·원가 자료, 거래 기록, 가정표 |
| 실적과 검증 | 이미 확인된 결과와 앞으로 확인할 가정을 구분했는가 | 매출, 사용 기록, 실험 결과 |
| 실행계획 | 담당자, 일정, 자원, 완료 기준이 구체적인가 | 일정표, 예산, 역할표 |
| 팀과 역량 | 계획을 실행할 경험과 부족한 역량의 보완책이 있는가 | 경력, 협력 계획, 채용 계획 |
| 재무와 자금 | 매출·비용 가정과 자금 사용이 활동 계획과 연결되는가 | 손익 추정, 현금흐름, 견적 |
| 위험과 대응 | 가장 큰 실패 조건과 확인 방법을 알고 있는가 | 위험 목록, 실험 계획, 중단 기준 |

## 적용 순서

1. 공식 공고·평가표·작성요령이 있는지 확인한다.
2. 있으면 공식 문구와 양식 항목을 요구사항추적표에 옮긴다.
3. 없으면 독자와 목적을 기준으로 위 질문 중 필요한 것만 선택한다.
4. 공식 배점이 없으면 임의 점수를 만들지 않는다.
5. 모든 필수 요구사항을 초안의 위치와 근거에 연결한다.
