# 부산대학교 모두의 창업 선택 참고자료

이 파일은 범용 기본값이 아니다. 사용자가 해당 프로그램의 현재 공식 공고·평가표를 제공한 경우에만 원문 대조용으로 사용한다. 과거 일정이나 대화 속 날짜를 현재 값으로 사용하지 않는다.

## 원문에서 다시 확인할 항목

- 운영기관과 트랙
- 제출물 명칭, 마감, 수정 가능 여부
- 평가영역과 공식 배점
- 작성 양식의 질문, 글자 수, 페이지 제한

## 과거 자료에 등장한 평가영역 예시

| 평가영역 | 원문 대조 질문 | 필요한 자료 예시 |
|---|---|---|
| 도전의 진정성 | 왜 이 문제를 발견했고 왜 본인이 해결하려는가 | 문제 발견 경험, 고객 사례, 개발 배경 |
| 사회적 가치 | 기존 대안과 무엇이 다르고 누구에게 어떤 변화가 생기는가 | 대안 비교, 기대효과 |
| 아이디어 구체성 | 누가 쓰고 어떻게 구현·검증·사업화할 것인가 | 목표고객, 수익 구조, MVP, 실행계획 |

공식 원문과 다른 내용은 사용하지 않는다. 공식 배점이 확인되지 않으면 점수를 만들지 않는다.
