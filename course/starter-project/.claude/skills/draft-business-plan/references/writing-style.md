# 사업계획서 문체와 서식 기준

## 적용 순서

1. 최신 공식 양식·작성요령·글자 수 제한을 가장 먼저 따른다.
2. 사용자가 승인한 기존 문서나 표현 예시가 있으면 그 형식을 이어간다.
3. 별도 기준이 없을 때만 아래 기본값을 사용한다.

작성 전에 적용할 문체, 번호 체계, 목록, 들여쓰기, 표와 단위 기준을 짧게 정한다. 초안 중간에 기준을 임의로 바꾸지 않는다.

## 문체와 문단

- 공식 지침이 없으면 `~한다`, `~이다` 문체를 기본으로 사용하고, `~합니다` 문체와 혼용하지 않는다.
- 한 문단에 하나의 핵심만 담는다. 첫 문장에 답을 쓰고 뒤에 근거, 실행 방법, 의미를 이어 쓴다.
- 주어와 행동을 분명하게 쓰고, 한 문장에 서로 다른 주장을 여러 개 엮지 않는다.
- 숫자·일정·대상·행동이 있는 구체적인 표현을 사용하고, `효과적`, `혁신적`, `다양한` 같은 모호한 수식어는 근거 없이 쓰지 않는다.
- 목록은 명사형이면 명사형, 완전한 문장이면 완전한 문장으로 맞추고 문장부호도 같게 적용한다.

## 번호 체계와 들여쓰기

- 공식 양식의 장·절 번호와 순서를 유지한다. 기준이 없으면 `1. 장` → `1.1 절` → `(1) 항목` 순으로 최대 3단계만 사용한다.
- 중간 번호를 건너뛰지 않고, 같은 단계에서 서로 다른 번호 형식을 섞지 않는다.
- 들여쓰기는 공백이나 탭을 반복해 만들지 말고 문서의 문단·목록 스타일을 사용한다.
- 같은 단계의 목록은 같은 들여쓰기를 적용하고, 두 줄 이상으로 이어지면 둘째 줄을 본문의 시작 위치에 맞춘다.
- 본문 단락에 불필요한 줄 바꿈과 빈 줄을 추가해 분량을 늘리지 않는다.

## 표와 숫자

- 표는 비교, 일정, 예산처럼 반복되는 항목을 한눈에 볼 필요가 있을 때만 사용한다.
- 한 열에는 하나의 기준만 두고, 표 제목·머릿글·단위·기준일을 분명하게 쓴다.
- 같은 열의 숫자는 동일한 단위와 자릿수를 사용하고, 합계·비율·원단위의 계산 기준을 표 아래에 적는다.
- 표 안에 긴 서술을 억지로 넣지 말고, 핵심값은 표에 두고 설명은 본문으로 분리한다.
- 외부 사실과 숫자를 사용한 표에는 출처와 기준일을 연결한다.

## HWPX에 반영할 때

- 마크다운 기호를 그대로 넣지 말고 원본 HWPX의 제목·본문·목록·표 스타일을 유지한다.
- 공백·탭·줄 바꿈으로 들여쓰기나 페이지 배치를 임의로 만들지 않는다.
- 입력 후 표 너비, 행 높이, 자동 줄 바꿈, 글자 겹침, 문단 번호, 페이지 넘김을 한글 화면에서 확인한다.
