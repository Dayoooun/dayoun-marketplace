# 참가자 사전 준비 안내

설치와 로그인은 수업 48시간 전까지 완료합니다. 수업 당일에는 새 프로그램을 설치하지 않고 Green·Yellow·Red 중 가능한 경로로 바로 시작합니다. 경로는 실력 등급이 아닙니다.

## 모두가 준비할 것

- 개인 노트북, 충전기, 마우스
- ChatGPT 계정 로그인과 간단한 요청 1회 성공
- 8월 14일 제출본의 읽기 전용 사본
- 공유 가능한 회사·팀·아이디어 소개자료 1개
- 공고문·부산대 평가지표·현재까지 받은 멘토 의견
- 강사가 제공한 스타터 프로젝트, 완성 예시, 오프라인 근거팩

개인 자료에는 최소한 아이템 한 문장, 목표고객, 고객 문제, 현재 대안, 확인된 사실, 아직 검증하지 않은 가정을 준비합니다. 개인정보·영업비밀은 마스킹합니다.

## GPT 공통 경로 확인

ChatGPT 또는 평소 사용하는 생성형 AI에서 다음 요청을 보내 정상 응답이 오는지 확인합니다.

```text
사업계획에서 사실, 가정, 향후 계획을 구분하는 기준을 세 줄로 설명해줘.
```

여기까지 성공하면 Yellow 경로로 네 가지 필수 실습을 완주할 수 있습니다.

## Codex 확장 경로 확인

프로젝트 파일을 직접 관리하려면 다음 항목을 확인합니다.

```powershell
codex --version
codex login status
python --version
codex plugin marketplace add Dayoooun/dayoun-marketplace --ref main
codex plugin add modoo-startup-plan@dayoun
```

Codex를 새로 시작한 뒤 다음처럼 준비 상태만 확인합니다.

```text
$complete-modoo-plan 준비 상태만 점검해줘. 아직 파일은 만들거나 수정하지 마.
```

## 내 실습 경로

| 경로 | 조건 | 수업 방식 |
|---|---|---|
| Green | GPT·Codex·Python·웹이 정상 | 개인 프로젝트와 파일형 확장 |
| Yellow | GPT는 가능하지만 나머지 중 하나가 불안정 | 스타터 프로젝트·오프라인 근거팩·공통 워크시트 |
| Red | 로그인·사용량·기기 문제로 개인 AI 사용이 어려움 | 2인 1조 검토자 역할·완성 예시·인쇄 활동지 |

## 한글·HWPX는 선택 경로

- 기본 수업에서는 제출본 원본을 수정하지 않습니다.
- 부산대가 제출 후 수정을 허용하고 강사가 실제 양식을 사전 검증한 경우에만 개인 HWPX를 사용합니다.
- 기본 HWPX 실습은 강사가 플레이스홀더를 넣은 교육용 샘플로 진행합니다.
- 한글이 없거나 HWPX가 열리지 않아도 수동 치환표까지 작성하면 정상 경로입니다.
- 스캔 결과 플레이스홀더가 0개이면 성공이 아니라 수동 매핑으로 전환합니다.

## 보안과 본인 책임

- 주민등록번호, 계좌번호, 신분증, 고객명단, 비공개 계약서는 넣지 않습니다.
- 근거 없는 숫자·계약·인증·특허는 만들지 않고 `{확인필요}`로 남깁니다.
- AI 결과는 참가자가 원문과 대조하고 직접 수정·승인합니다.
- 제출본 원본, 수업 작업본, 활동 결과물을 서로 다른 파일로 보관합니다.
