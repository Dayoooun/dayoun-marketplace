# 2시간 커리큘럼 초안

> 상태: 사용자 검토 전 초안. 실제 부산대 양식과 제출 후 수정 가능 여부를 확인한 뒤 확정합니다.

## 강의 개요

- 타이틀: AI로 고도화하는 모두의 창업 사업계획서: 시장조사·아이디어 검증·HWPX 실습
- 대상: 부산대학교 모두의 창업 1기 선정자
- 시간: 2026년 8월 19일 10:00~12:00
- 방식: 시연 25% + 개인·짝 실습 75%
- 핵심 도구: Codex와 dayoun 마켓플레이스의 교육용 스킬
- 대체 경로: 플러그인 설치 실패 시 프로젝트 내 로컬 스킬, 사용량 소진 시 짝 실습, 인터넷 실패 시 오프라인 근거팩

## 학습목표

참가자는 수업이 끝날 때 다음 다섯 가지를 보유합니다.

1. 표준 프로젝트 폴더와 회사사실표
2. 부산대 평가기준과 제출요건을 연결한 체크표
3. 출처·기준일·단위가 있는 시장·고객 근거 3~5개
4. 문제–고객–해결–차별성–실행계획이 연결된 핵심 초안 1개
5. 실제로 열리는 HWPX 보완본 또는 HWPX 치환표

2시간 안에 전체 문서를 대신 작성하는 것이 목표가 아닙니다. 핵심 항목 하나를 조사부터 HWPX 반영까지 한 바퀴 완주하고, 같은 방식을 나머지 항목에 반복할 수 있게 만드는 수업입니다.

## 공식 평가 흐름과의 정렬

부산대 일반·기술트랙 공개 평가지표는 다음 세 영역을 중심으로 봅니다. 공식 가중치는 공개되지 않았으므로 교육 자료에서 임의 배점을 공식 점수처럼 사용하지 않습니다.

| 공개 평가영역 | 수업에서 만드는 근거 |
|---|---|
| 도전의 진정성 | 대표자의 문제 발견 경험, 신청·개발 배경, 해결 의지 |
| 사회적 가치 | 독창성·차별성, 수혜자 변화, 기대효과 |
| 아이디어 구체성 | 목표고객, 시장성, 구현·사업화 가능성, 검증계획 |

통합공고상 1R은 문서만이 아니라 프로그램 참여 과정과 멘토링 보고서 등 활동 결과물도 평가합니다. 따라서 수업은 보완 문장뿐 아니라 고객 검증 질문, 경쟁대안 표, 30일 실행계획, 멘토링 전후 변경기록까지 남기도록 설계합니다.

## 비주얼 자료 계획

- 모듈 1: 채팅형 AI와 에이전트형 작업의 차이 다이어그램
- 모듈 2: 마켓플레이스 설치 화면, 프로젝트 폴더 트리
- 모듈 3: 사실·근거·가정·계획 분류표, 부산대 평가기준 맵
- 모듈 4: 조사 질문 → 출처 → 증거 ID → 사업계획서 문장 흐름도
- 모듈 5: 문제–고객–해결–검증–BM 한 장 논리맵
- 모듈 6: HWP → HWPX 저장 → 중괄호 스캔 → 복사본 생성 흐름도
- 모듈 7: PASS/WARN/BLOCK 최종 점검표

## 확정 전에 확인할 사항

1. 8월 14일 제출물의 정확한 명칭과 8월 19일 이후 수정 가능 여부
2. 참가자가 일반·기술트랙인지, 로컬트랙이 섞여 있는지
3. 참가 인원, 개인 노트북 필참 여부, 앱 설치 가능 여부
4. 사업계획서·활동보고서·멘토링 보고서 원본 양식
5. 부산대 내부 평가표 또는 작성 유의사항 존재 여부
