# 교육자료 제작 목록

## 커리큘럼 확정 후 제작

- 강의 슬라이드 스토리보드
- 참가자용 한 장 빠른 시작 가이드
- 단계별 복사 프롬프트 카드
- 강사용 시연 스크린샷 12장 이상
- 모듈별 흐름도 7개
- 실습용 샘플 회사자료
- 실습용 HWPX와 완성본
- 오프라인 시장조사 근거팩
- PASS/WARN/BLOCK 최종 검토표
- 참가자용 다음 행동 30일 계획표

## 실제 양식 수령 후 교체

- HWPX 플레이스홀더 목록
- placeholder-values.json 예시
- 부산대 내부 평가기준 매핑
- 활동보고서·멘토링 보고서 항목 매핑
- 실제 제출 파일명·용량·페이지 제한

## 배포 전 검증

- 새 Windows 사용자 환경에서 설치
- 플러그인 설치 후 새 작업에서 6개 스킬 노출 확인
- 프로젝트 생성 스크립트 재실행 안전성 확인
- HWPX 스캔·치환·구조검증·한글 열기 확인
- 네트워크 없이 오프라인 경로 완주
- 구독 한도 소진 시 짝 실습 경로 점검
