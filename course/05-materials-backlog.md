# 교육자료 제작 목록

## P0 · 커리큘럼 확정 즉시 제작

- 강의 슬라이드 스토리보드
- 참가자용 한 장 빠른 시작 가이드: 제출본 보존 → 공백 진단 → 검증·변화기록 → 실행계획
- 부산대 공개 평가기준 공백진단표
- 검증·활동 기록지: 주장, 출처·고객근거, 기준일, 확인 결과, 한계, 다음 검증
- 멘토링 변화기록지: 기존 생각, 새 근거·피드백, 유지·수정·보류 결정, 이유
- 다음 공식 마감 실행카드: 행동, 담당, 기한, 완료 증거
- 1분 IR 핵심 메시지 템플릿: 문제, 고객, 해결, 차별성, 다음 검증
- 제출본 원본·작업 사본·활동 결과물 파일명과 폴더 구분 가이드
- AI 결과 본인검증 체크리스트: 본인 착상, 출처 확인, 허위·과장, 개인정보·영업비밀, 제출본 구분

## P1 · 두 가지 도구 경로 제작

- GPT 공통 경로용 단계별 복사 프롬프트 카드
- Codex 확장 경로용 스킬 호출·프로젝트 파일 예시
- 같은 입력을 GPT 공통 경로와 Codex 확장 경로로 처리한 비교 예시
- 최신 AI 업무 흐름 한 장: 채팅, 출처 기반 조사, 멀티모달, 파일형 에이전트
- 강사용 핵심 시연 화면: 제출본 보존, 공백 진단, 근거기록, 변화기록, 실행카드
- 예비창업자와 기존 창업자 모두 사용할 수 있는 익명화 샘플 아이디어 자료
- 오프라인 시장조사 근거팩
- 인터넷·사용량 장애 시 사용할 인쇄 워크시트
- 수업 중 20·40·60·80·100·110분 체크포인트표

## 실제 부산대 자료 수령 후 반영

- 8월 14일 제출물의 정확한 명칭과 제출본 보존 규칙
- 다음 공식 마감, 오디션 일정, IR 발표시간·형식
- 부산대 내부 평가기준 매핑
- 활동보고서·멘토링 보고서 항목 매핑
- 실제 활동 결과물의 파일명·용량·페이지 제한
- 일반·기술트랙 전용 여부와 로컬트랙 참가자 혼합 여부

## 제출 이후 수정 허용 시에만 제작

- 실제 HWPX 양식의 복사본과 플레이스홀더 목록
- `placeholder-values.approved.json` 예시
- 원본·제출본·보완본 파일명 규칙
- HWPX 스캔·치환·구조검증 예시와 한글 육안검토표
- 수정 불가 시 사용할 HWPX 대체 산출물 `보완 제안표`

## 배포 전 검증

- 수업 48시간 전 설치 안내와 자가점검 링크 배포
- 새 Windows 사용자 환경에서 Codex·플러그인 사전설치 경로 확인
- GPT 공통 경로가 Codex·플러그인 없이도 네 가지 필수 산출물을 만드는지 확인
- 프로젝트 생성 스크립트가 제출본 원본을 덮어쓰지 않는지 재실행 검증
- 네트워크 없이 오프라인 근거팩과 인쇄 워크시트로 핵심 실습 완주
- 구독 한도 소진 시 짝 실습 경로와 개인 산출물 분리 방법 점검
- 강의 110분 안에 필수 실습을 마치고 마지막 10분 버퍼가 유지되는지 리허설
- 실제 자료가 없는 참가자도 샘플 아이디어로 참여할 수 있는지 확인
- HWPX는 수정 허용·실제 양식 수령·사전 구조검증이 모두 끝난 경우에만 배포
